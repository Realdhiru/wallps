## 🚀 Setup & Integration

### 📦 Quick Clone
```bash
git clone git@github.com:Realdhiru/wallps.git ~/Pictures/Wallpapers
```

### ⚡ Sparse Checkout (Download Specific Categories)
To save bandwidth and only fetch the categories you use:
```bash
git clone --filter=blob:none --sparse git@github.com:Realdhiru/wallps.git ~/Pictures/Wallpapers
cd ~/Pictures/Wallpapers
git sparse-checkout set nord ocean dark gruvbox sakura
```

### 🖥️ Setting Wallpapers on Hyprland & Linux
* **`swww`** (Smooth transitions):
  ```bash
  swww img ~/Pictures/Wallpapers/blue/alone-night-sky-scenery.jpg --transition-type wipe
  ```
* **`hyprpaper`** (Static fast wallpaper engine):
  ```ini
  preload = ~/Pictures/Wallpapers/dark/pure-black-minimal.jpg
  wallpaper = ,~/Pictures/Wallpapers/dark/pure-black-minimal.jpg
  ```
* **`mpvpaper`** (Animated live video backends):
  ```bash
  mpvpaper '*' ~/Pictures/Wallpapers/videos/cracked-screen-cat.mp4 -o 'loop --no-audio'
  ```
