## 🚀 Download & Setup Guide

### 1. Clone the Collection
```bash
git clone git@github.com:Realdhiru/walpp.git ~/Pictures/Wallpapers
```

### 2. Download Specific Shades (Sparse Checkout)
```bash
git clone --filter=blob:none --sparse git@github.com:Realdhiru/walpp.git ~/Pictures/Wallpapers
cd ~/Pictures/Wallpapers
git sparse-checkout set dark blue   # only download dark and blue shades
```

### 3. Setting Wallpapers on Linux & Hyprland
* **hyprpaper**:
  ```ini
  preload = ~/Pictures/Wallpapers/dark/pure-black-minimal.jpg
  wallpaper = ,~/Pictures/Wallpapers/dark/pure-black-minimal.jpg
  ```
* **swww** (smooth transitions):
  ```bash
  swww img ~/Pictures/Wallpapers/blue/monterey-nord-dunes.png --transition-type wipe
  ```
* **mpvpaper** (for live MP4 wallpapers):
  ```bash
  mpvpaper '*' ~/Pictures/Wallpapers/videos/cracked-screen-cat.mp4 -o 'loop --no-audio'
  ```
* **feh**:
  ```bash
  feh --bg-fill ~/Pictures/Wallpapers/dark/nixos-snowflake-minimal.png
  ```
